# Справочник по API Wildberries

Шпаргалка для починки скилла, когда WB в очередной раз обновит методы.
Все адреса лежат в одном месте — словарь `ENDPOINTS` в начале `scripts/wb_api.py`.
Актуальная документация: https://dev.wildberries.ru

## Методы, которые использует скилл

| Ключ в ENDPOINTS | Метод и адрес | Зачем |
|---|---|---|
| `spisok_kampaniy` | `GET /adv/v1/promotion/count` | список id кампаний с типами и статусами |
| `detali_kampaniy` | `POST /adv/v1/promotion/adverts` | названия, ставки, артикулы. Не больше 50 id за запрос |
| `statistika` | `POST /adv/v2/fullstats` | показы, клики, расход, заказы, выручка |
| `postavit_stavku` | `POST /adv/v0/cpm` | смена ставки |
| `balans` | `GET /adv/v1/balance` | остаток на счету и бонусы |
| `voronka` | `POST /api/v2/nm-report/detail` (seller-analytics-api) | заказы и выручка по артикулам |

Первые пять — на хосте `advert-api.wildberries.ru`, последний — на
`seller-analytics-api.wildberries.ru`. Токен передаётся в заголовке
`Authorization` как есть, без `Bearer`.

## Ограничения по частоте

- `/adv/v2/fullstats` — **1 запрос в минуту**. Поэтому статистика по всем
  кампаниям берётся одним запросом: метод принимает массив кампаний.
- `nm-report/detail` — порядка 3 запросов в минуту.
- Остальные — примерно 5 запросов в секунду; в клиенте стоит пауза 0,25 сек.
- На 429 клиент сам ждёт 60 секунд и повторяет.

## Типы кампаний

| Код | Что это |
|---|---|
| 4 | каталог |
| 5 | карточка товара |
| 6 | поиск |
| 7 | главная страница |
| 8 | автоматическая |
| 9 | аукцион (АРК) |

Типы 4-7 — старые форматы, у большинства кабинетов их уже нет. Живые
кампании обычно 8 и 9.

## Статусы

| Код | Что значит |
|---|---|
| -1 | удаляется |
| 4 | готова к запуску |
| 7 | завершена |
| 8 | отказался |
| 9 | идут показы |
| 11 | на паузе |

Скилл смотрит только на статусы 9 и 11 — остальные деньги не тратят.

## Где у кампании лежит ставка

Формат ответа разный у разных типов, поэтому `stavka_kampanii()` в `wb_api.py`
разбирает все три варианта и не зашивает структуру жёстко:

- **тип 8 (автоматическая):** `autoParams.cpm`, предмет — `autoParams.subject.id`.
  Ставка одна.
- **тип 9 (АРК):** массив `unitedParams`, в каждом блоке два значения —
  `searchCPM` (поиск) и `catalogCPM` (каталог). Предмет — `subject.id`.
- **старые типы:** массив `params`, ставка в `price`.

При смене ставки в тело `POST /adv/v0/cpm` идут: `advertId`, `type`, `cpm`,
`param` (id предмета) и для АРК — `instrument`: **6 — поиск, 4 — каталог**.
Скилл берёт эти значения из ответа `detali_kampaniy`, а не подставляет
константы, — так смена формата ломает меньше.

## Частые ошибки

- **401** — токен не тот, истёк или создан без нужных категорий. Лечится
  пересозданием токена в кабинете под учётной записью владельца.
- **403** — токен есть, но не хватает категории «Продвижение» или «Аналитика».
- **400 / 404 на рабочем методе** — WB обновил API. Скажи агенту «почини вызов
  по документации dev.wildberries.ru».
- **429** — превышен лимит запросов, клиент сам подождёт минуту.
- **Ставка не изменилась в кабинете** — API применяет её с задержкой до пары
  минут. Проверять сразу после запроса бессмысленно.
- **Пустая статистика за сегодня** — WB отдаёт данные текущего дня с задержкой.
  Для разбора берите вчерашний день и раньше.

## Что скилл сознательно не вызывает

Методов остановки и запуска кампаний, смены дневного бюджета и пополнения
баланса в `ENDPOINTS` нет. Это не забыли добавить — так задумано: агент не
должен уметь останавливать рекламу и тратить деньги со счёта. Если такой вызов
понадобится, добавлять его должен человек осознанно.
